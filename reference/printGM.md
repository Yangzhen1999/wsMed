# Print Formatted SEM Model Syntax

Formats and prints the SEM model syntax generated by `GenerateModelCN`,
`GenerateModelCP`, `GenerateModelP`, and `GenerateModelPC`. It organizes
the equations into labeled sections for better readability.

## Usage

``` r
printGM(x, ...)
```

## Arguments

- x:

  A list or character string containing SEM model syntax. If `x` is a
  [`wsMed()`](https://yangzhen1999.github.io/wsMed/reference/wsMed.md)
  result, it will extract and print the model syntax. If `x` is a
  `GenerateModel*()` result, it will format and print the model.

- ...:

  Additional arguments (not used).

## Value

Invisibly returns the formatted SEM model syntax.
