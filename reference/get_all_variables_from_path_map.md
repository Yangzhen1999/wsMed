# Extract All Variables Needed for Standardization

Extracts predictor and outcome variable names from a path
standardization map.

## Usage

``` r
get_all_variables_from_path_map(path_std_map)
```

## Arguments

- path_std_map:

  A named list returned by
  [`build_path_std_map()`](https://yangzhen1999.github.io/wsMed/reference/build_path_std_map.md).

## Value

A character vector of variable names.
