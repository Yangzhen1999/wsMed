Comparing wsMed and MEMORE

What is compared?

These examples compare unstandardized indirect effects and their contrasts in a parallel and a serial model. They use the package’s simulated example_data, not the empirical manuscript dataset. The MEMORE 3.0 reports are stored SPSS output; they are not rerun when this page is built. The wsMed analyses below are executed when the tutorial is rebuilt.

Setting Matched choice
Data The same 100 complete simulated participant rows
Direction Condition 2 minus condition 1 for every pair
Model The same mediator ordering and directed connections
Covariates and moderator None; MEMORE does not support covariates
Scale Unstandardized effects
Indirect-effect inference 5,000 participant bootstrap samples; 95% percentile CIs

The default wsMed analysis uses Monte Carlo inference. Here we explicitly request bootstrap inference and 5,000 replicates to match the method and sample count in the stored reports. The two programs do not use identical resamples, so matching settings does not imply identical CI endpoints.

Why focus on indirect effects? In these MEMORE reports, total and direct effects use regression-based SEs and t intervals. The wsMed bootstrap report uses bootstrap SEs and percentile CIs for all effects. Thus the indirect-effect intervals below have a common interpretation; the total- and direct-effect intervals should not be treated as equivalent output. Contrasts are calculated within each bootstrap sample, retaining dependence between indirect effects.

Parallel mediation

The three mediators are A, B and C; the outcome is D. There are no directed connections among mediators.

result1 <- wsMed(
  data = example_data,
  M_C1 = c("A1", "B1", "C1"),
  M_C2 = c("A2", "B2", "C2"),
  Y_C1 = "D1",
  Y_C2 = "D2",
  ci_method = "bootstrap",
  bootstrap = 5000
)
print(result1)

Serial mediation

The two mediators are A and B; the outcome is C. form = "CN" adds the A-to-B connection, matching the stored MEMORE serial specification. The third indirect effect now follows A → B → C.

result2 <- wsMed(
  data = example_data,
  M_C1 = c("A1", "B1"),
  M_C2 = c("A2", "B2"),
  Y_C1 = "C1",
  Y_C2 = "C2",
  form = "CN",
  ci_method = "bootstrap",
  bootstrap = 5000
)
print(result2)

Reading the comparison

The indirect-effect and contrast point estimates agree to the four decimal places available in the stored MEMORE reports. Percentile CI endpoints can differ because of the bootstrap resamples and quantile conventions.

Centering also matters in the serial example. MEMORE recenters mediator averages in each bootstrap sample, while wsMed resamples variables centered during data preparation. This can change downstream-mediator intercepts and their indirect-effect draws, even with identical resamples. Interpret the serial intervals in light of this additional implementation difference.

Matching point estimates establishes agreement for these fitted models; it does not by itself validate interval coverage or other model specifications.

The comparison does not establish agreement for standardized or moderated effects. Their definitions and scale conventions need separate checks; see Standardized effects. For a first analysis with the default wsMed settings, use Get started.
