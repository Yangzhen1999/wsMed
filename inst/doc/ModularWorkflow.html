Reuse a fit: the staged workflow

The staged interface separates model specification, fitting, and inference. You can inspect the output after each stage and reuse it in the next one. This guide follows one parallel-mediation example through those three stages, then shows how to read and extract the results. wsMed() remains available for completing the analysis in one call, as shown in Get started.

The workflow at a glance

Stage and call Returned object What is available
1. Specify
wsmed_model()		 model: a wsmed_model Variable pairs, condition order, mediator structure, covariates and moderator settings.
2. Fit
wsmed_fit(model, data)		 fit: a wsmed_fit Fitted parameters and native SEs, prepared data, model syntax, backend fits and diagnostics.
3. Infer
wsmed_infer(fit)		 inference: a wsmed_inference The original fit, joint draws, inference settings and draw diagnostics.
4. Read or extract
summary(inference) or wsmed_effects(inference)		 A summary or wsmed_results Effect estimates, SEs, CIs, effect draws and reporting settings.

The first three steps create the analysis objects. The fourth uses those objects to produce tables, plots and contrasts; it does not fit or sample again. At each step below, start with the default display and use the extraction examples only when you need the underlying values.

data(example_data)

These simulated data are complete and in wide format, with one row per participant. A1/A2 and B1/B2 are the mediator pairs; D1/D2 are the outcome pair.

1. Specify the model

Use wsmed_model() to describe the analysis before supplying data. Name each pair with the same two conditions. Here, every difference is after minus before. The names A and B identify the mediator roles in paths and output.

model <- wsmed_model(
  outcome = c(before = "D1", after = "D2"),
  mediators = list(
    A = c(before = "A1", after = "A2"),
    B = c(before = "B1", after = "B2")
  )
)
print(model)
#> wsMed model: P 
#> Difference: after - before 
#> Mediators: A, B

Parallel mediation is the default. The main specification arguments are:

Argument What it specifies
outcome A named pair of outcome columns. Its order defines the condition contrast.
mediators A named list of mediator pairs. Order determines mediator numbering.
structure "parallel", "serial", "serial_parallel", "parallel_serial", or "custom".
paths For custom models, arrows using mediator role names and Y, such as "A -> B" and "B -> Y".
covariates A list with between column names and/or within named pairs.
moderator A list specifying the moderator column and the paths with interactions.

What can you inspect now?

specification <- wsmed_inspect(model, "model")
specification$conditions
#> [1] "before" "after"
specification$mediator_names
#> [1] "A" "B"
column_map <- specification$input_vars
Item Access
Complete specification wsmed_inspect(model, "model")
Condition names and order model$conditions
Mediator role names model$mediator_names
Paired columns and predictor settings model$input_vars
Model-form code and custom edges model$form, model$paths

This object contains no observations, fitted estimates or CIs. Model syntax, transformed data and fit diagnostics become available after fitting.

2. Fit the model

Pass the specification and the wide dataset to wsmed_fit():

fit <- wsmed_fit(
  model,
  data = example_data
)
print(fit)
#> wsMed fit: P | DE | 1 fitted dataset(s)
#> Observations: 100 of 100 input rows
#> Converged: 1 of 1 
#> Condition contrast: after - before 
#> Post-fit admissibility: 1 of 1 ; excluded rows: 0

print(fit) reports the sample size, convergence and diagnostic summary. The fitting default is missing = "error", so missing analysis values require an explicit choice of "listwise", "fiml", or "mi". This differs from the listwise-deletion default of wsMed(); it makes no difference for the complete data used here. Missing-data examples appear below.

Inspect the generated equations and check the fitted datasets:

cat(wsmed_inspect(fit, "syntax"))
#> Ydiff ~ cp*1 + b1*M1diff + d1*M1avg + b2*M2diff + d2*M2avg
#> M1diff ~ a1*1
#> M2diff ~ a2*1
#> indirect_1 := a1 * b1
#> indirect_2 := a2 * b2
#> total_indirect := indirect_1 + indirect_2
#> total_effect := cp + total_indirect
fit_checks <- wsmed_inspect(fit, "diagnostics")
fit_checks$by_dataset[c("dataset", "n.used", "converged", "admissible", "warnings")]
#>   dataset n.used converged admissible warnings
#> 1       1    100      TRUE       TRUE        0
fit_checks$warnings
#> character(0)

converged records whether estimation converged; admissible records the backend post-fit check. Review warnings and failed checks before proceeding. Convergence alone does not establish that the model or missing-data assumptions are appropriate. For additional backend diagnostics, retrieve the fits with wsmed_inspect(fit, "fits") and inspect the relevant fitted dataset.

You can also obtain effect point estimates before inference:

point_effects <- wsmed_effects(fit)
print(point_effects)
#> wsMed indirect | raw scale | point 
#> Point estimates only; no simulation-based SE or intervals.
#> Condition contrast: after - before 
#>               Estimate
#> indirect_1: A  0.00131
#> indirect_2: B -0.00112
#> Use as.data.frame() for the full-precision table and metadata.

This defaults to the specific indirect effects. No simulation-based effect SEs or CIs are available yet. confint(fit) therefore asks you to run wsmed_infer() first; plot(fit) likewise shows point estimates only.

3. Perform inference

Pass the existing fit to wsmed_infer():

inference <- wsmed_infer(
  fit,
  seed = 123
)
print(inference)
#> wsMed inference: mc | 20000 valid draws of 20000 requested
#> 95% effect intervals: percentile; stored parameter-table convention: percentile
#> Inference draws: 20000 retained of 20000 ; 0 excluded before effect extraction.
#> Use summary() or wsmed_effects() to select effects.

The defaults are Monte Carlo inference, 20,000 draws and 95% CIs. The seed is specified for reproducibility; the staged default is seed = NULL. print(inference) reports the inference method and the number of retained draws. It does not display the effect table; use summary(inference) next.

Inference checks wsmed_inspect(inference, "diagnostics") Requested, retained and invalid draws, plus recorded warnings.
Parameter point estimates coef(inference) The same fitted parameter estimates as coef(fit).
Empirical parameter covariance vcov(inference) Covariance of stored draws for the model parameters.
Parameter CIs confint(inference) Percentile CIs for model parameters.

The coefficients within a row belong to the same draw. Keeping that pairing is necessary when forming products or contrasts. Point estimates remain those computed from the fitted model; they are not replaced by averages of the draws. For conditional or standardized effect draws, use the result object in step 4, which applies the requested transformations and records any additional exclusions.

wsmed_inspect(inference, "diagnostics") describes inference. To recover the fitting checks, use wsmed_inspect(inference$fit, "diagnostics").

For indirect-effect CIs, use a summary or an effect result object, rather than confint(inference). For example:

effects <- wsmed_effects(inference)
print(effects)
#> wsMed indirect | raw scale | mc 
#> 95% percentile intervals; 20000 joint draws; SE from effect draws
#> Condition contrast: after - before 
#>               Estimate Std. Error CI lower CI upper
#> indirect_1: A  0.00131    0.00321 -0.00460  0.00892
#> indirect_2: B -0.00112    0.00257 -0.00762  0.00308
#> Inference draws: 20000 retained of 20000 ; 0 excluded before effect extraction.
#> Use as.data.frame() for the full-precision table and metadata.

#>                   2.5 %      97.5 %
#> indirect_1 -0.004600745 0.008917406
#> indirect_2 -0.007616873 0.003084259

wsmed_effects() defaults to specific indirect effects. Its wsmed_results object stores $table, $point, $draws, $draw_ids, $query, and $diagnostics. $query records the requested effect family, reporting scale, moderator values and confidence level. In contrast, summary() defaults to all core effects and adds the path-coefficient table and $info.

To compare the two indirect effects, use the same joint draws:

contrast <- wsmed_contrasts(
  effects,
  list(B_minus_A = c(indirect_2 = 1, indirect_1 = -1))
)
print(contrast)
#> wsMed contrasts | raw scale | mc 
#> 95% percentile intervals; 20000 joint draws; SE from effect draws
#> Condition contrast: after - before 
#> Contrast direction (signed weights):
#>  B_minus_A: +1 * B -1 * A
#>           Estimate Std. Error CI lower CI upper
#> B_minus_A -0.00243    0.00411 -0.01178  0.00492
#> Inference draws: 20000 retained of 20000 ; 0 excluded before effect extraction.
#> Use as.data.frame() for the full-precision table and metadata.

The contrast CI comes from the draw-by-draw difference, not from subtracting the endpoints of two separate CIs. See Read and export results for further selection and export examples.

Decide where to restart after a change

What changed? Where to continue
Variable roles, mediator structure, covariates or moderated paths Specify a new model, then fit and infer.
Dataset, missing-data strategy or imputation settings Run wsmed_fit() with the relevant model, then infer.
Monte Carlo versus bootstrap, number of draws, or inference seed Run wsmed_infer() on the existing fit.
Selected effects, moderator probes, confidence level or reporting scale Query the existing inference or result object.
Labels, rounding or plot appearance Reprint or replot existing results.

Alternatively, set standardized = TRUE in wsmed_fit() to save standardized reporting as the default. This does not change model fitting. Standardized effects use the model-implied scales and propagate their uncertainty across the joint draws; see standardized effects.

To create a separate bootstrap inference from the same fit:

bootstrap_inference <- wsmed_infer(
  fit,
  method = "bootstrap",
  seed = 123
)
summary(bootstrap_inference)

This uses the default 2,000 bootstrap replicates. Bootstrap necessarily fits the resampled datasets; it retains the original fitted object. The interval argument controls the stored legacy parameter table. Effect and confint() methods use percentile intervals, including when that parameter table uses a bias-corrected convention.

Add a custom structure and moderator

Changes to the model belong in step 1. In the staged interface, custom arrows and moderated slopes use the mediator role names, rather than the M1/M2 and MP labels used by wsMed(). The following model has A to C, C to the outcome, and B to the outcome, with moderation of the first two slopes:

moderated_model <- wsmed_model(
  outcome = c(before = "D1", after = "D2"),
  mediators = list(
    A = c(before = "A1", after = "A2"),
    B = c(before = "B1", after = "B2"),
    C = c(before = "C1", after = "C2")
  ),
  structure = "custom",
  paths = c("A -> C", "C -> Y", "B -> Y"),
  moderator = list(
    variable = "D3",
    interactions = c("A -> C", "C -> Y")
  )
)
mod_fit <- wsmed_fit(
  moderated_model,
  data = example_data
)
mod_inference <- wsmed_infer(
  mod_fit,
  seed = 123
)

conditional$table contains the estimates and CIs at those values; conditional$draws contains the corresponding joint effect draws. Supply raw values even when requesting standardized output. Invalid standardized draws are excluded jointly, with original identities recorded in $diagnostics$invalid_draw_ids. Plot bands are pointwise, not simultaneous.

For categorical covariates and moderators, use unordered factors with explicit levels; the first level is the reference group. Numeric 0/1 columns remain continuous in the staged interface unless converted to factors. Default categorical probes include all observed levels. See categorical predictors for coding and group contrasts.

Handle missing data at the fitting stage

The model specification can be reused with incomplete data. To demonstrate, remove a few measurements from a copy of the simulated data:

incomplete_data <- example_data
incomplete_data$A2[1:5] <- NA
incomplete_data$D2[6:10] <- NA
missing What fitting does Inference methods
"error" (default) Requires complete analysis variables. Monte Carlo or bootstrap.
"listwise" Uses complete cases for the analysis variables. Monte Carlo or bootstrap.
"fiml" Handles missing analysis variables during model fitting. Monte Carlo or bootstrap.
"mi" Imputes original measurements, constructs variables within each completed dataset, fits and pools. Monte Carlo only.

For FIML, use wsmed_fit(model, incomplete_data, missing = "fiml"). Categorical predictors must be fully observed under FIML. For MI, set its controls at fitting and the inference seed separately:

mi_fit <- wsmed_fit(
  model,
  data = incomplete_data,
  missing = "mi",
  mi = list(seed = 123)
)
mi_inference <- wsmed_infer(
  mi_fit,
  seed = 604
)
print(mi_fit)
#> wsMed fit: P | MI | 5 fitted dataset(s)
#> Observations: 100 of 100 input rows
#> Converged: 5 of 5 
#> Condition contrast: after - before 
#> MI: per-imputation centering; first-imputation reporting reference.
#> Post-fit admissibility: 5 of 5 ; excluded rows: 0
print(mi_inference)

This uses the default five imputations and numeric imputation method. Choose appropriate settings for an actual analysis; for example, mi = list(m = 20, method = "pmm", seed = 123) explicitly requests 20 predictive-mean-matching imputations. A new wsmed_infer(mi_fit, ...) call reuses the fitted imputations and pooled quantities without reimputing.

wsmed_inspect(mi_fit, "data") returns one data frame, not the complete list of imputations. Do not use the first imputation’s backend fit as a substitute for pooled inference. The workflow retains per-imputation centering and the first-imputation moderator reference for reporting.

For externally generated imputations, pass mi = list(completed = completed) with missing = "mi". completed can be a list of completed wide datasets or a mice mids object. Their number is inferred; omit internal imputation-method and seed controls. With moderation, default main-effects imputation may not preserve the specified interactions. See model-compatible imputation for choosing and supplying an appropriate imputation model.

Save a stage and continue later

Save the inference object to retain both its fit and its draws:

saveRDS(
  inference,
  "mediation-inference.rds"
)
restored <- readRDS("mediation-inference.rds")
summary(restored)

Saving fit instead retains the fitted model for a later wsmed_infer() call. An analysis manifest records settings, diagnostics and software versions:

manifest <- wsmed_reproducibility(inference)
names(manifest)
#> [1] "report_schema_version" "model"                 "analysis"             
#> [4] "fitting_versions"      "fit_diagnostics"       "inference"            
#> [7] "export_environment"

The manifest does not contain observations or draws and does not replace the saved object, data and analysis script. Seeded workflow calls restore the caller’s random state; seed = NULL advances the current random stream. For older saved objects, compatibility checks may require refitting or regenerating inference; the accessors do not silently reconstruct missing metadata. See diagnostics and migration.
