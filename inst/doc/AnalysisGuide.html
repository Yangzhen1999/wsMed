Choose an analysis

Start with your research question, then follow the relevant guide. For a first analysis, complete Get started; it uses wsMed() throughout. All models here require two within-subject conditions with paired measurements.

Prepare your data

Use one row per participant, separate columns for the two conditions, and the same mediator order in both conditions. Decide which condition is subtracted from which before fitting: wsMed uses condition 2 minus condition 1.

Choose your model

Research structure form Meaning / next step
Parallel pathways "P" Each mediator forms a separate pathway; start with the quick start.
Serial pathways "CN" Mediators are connected in order; see model selection.
Serial-parallel structure "CP" A serial component feeds parallel pathways; inspect the diagram in the model description.
Parallel-serial structure "PC" Parallel pathways feed a later mediator; inspect the diagram in the model description.
User-defined pathways "UD" Specify the directed mediator connections; see custom models.

Choose the structure using your research design and substantive assumptions. Check mediator ordering against the diagram and generated equations; the two mixed structures are not interchangeable. Their equation articles provide definitions rather than additional required steps for an ordinary fit.

Add moderation

Moderator Guide What to report
Continuous Specify moderated paths Conditional effects at meaningful raw values, with a curve or selected-level plot.
Categorical Fit and compare groups Reference coding, group-specific effects and intervals for group differences.

Declare categorical between-subject covariates and moderators as unordered factors before using either interface. Set factor levels explicitly; the first level is the reference group. The categorical predictor guide shows binary and multicategory coding. Specify which paths are moderated rather than assuming that every path includes an interaction.

Handle missing data

Situation Where to start
Complete data or deliberate complete-case analysis Na = "DE"; inspect the number of retained participants.
Full-information maximum likelihood Na = "FIML"; see options and restrictions.
Multiple imputation Na = "MI"; see imputation options.
Multiple imputation with moderation interactions Model-compatible imputation, including external completed datasets.

The choice depends on the missing-data assumptions and variable types. Default main-effects imputation may not preserve moderation interactions. Do not treat successful fitting or reproducible output as proof that an imputation model is suitable. Missing categorical predictors have additional restrictions.
