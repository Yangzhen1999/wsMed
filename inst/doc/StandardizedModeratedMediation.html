What is standardized?

For a two-condition design, define \(D M=M_2-M_1\) and \(D Y=Y_2-Y_1\). PrepareData() centers the mediator average component, but does not center these differences. Standardization divides a difference by its marginal model-implied SD, preserving its mean condition effect.

Write \(s_M=SD(D M)\) and \(s_Y=SD(D Y)\). Without moderation,

\[ a^*=a/s_M,\qquad b^*=b s_M/s_Y,\qquad c'^*=c'/s_Y, \qquad IE^*=ab/s_Y. \]

The condition contrast retains its original unit. In a serial chain, the intermediate mediator SDs cancel. Thus every complete indirect effect, its contrast with another complete indirect effect, the total indirect effect and the total condition effect use the outcome-difference SD.

These are marginal SDs implied by the fitted model, not residual SDs, group-specific SDs or SDs conditional on a selected moderator value. The same endpoint scales apply at every moderator value within a fit.

Continuous moderators: two different quantities

For a centered moderator \(w_c=w-\bar w\), suppose the conditional paths are \(a(w_c)=a+a_w w_c\) and \(b(w_c)=b+b_w w_c\). Then

\[ IE^*(w_c)=\frac{(a+a_w w_c)(b+b_w w_c)}{s_Y}, \qquad b^*(w_c)=(b+b_w w_c)\frac{s_M}{s_Y}. \]

The standardized interaction coefficient is instead

\[ b_w^*=b_w\frac{s_M s_W}{s_Y},\qquad a_w^*=a_w\frac{s_W}{s_M}. \]

Standardized interaction coefficients are expressed per SD of a continuous moderator. In contrast, summary(result) reports conditional effects and paths at selected raw moderator values. Conditional tables and curves evaluate effects at fixed numerical moderator values in the original units. To recover a conditional slope from fully standardized coefficients, use \(b^*(w_c)=b^*+b_w^*(w_c/s_W)\). The scale of an interaction is the product of its component scale factors, not the SD of the observed product column.

Categorical moderators

Confidence intervals, bootstrap and both engines

Each valid joint draw supplies both regression coefficients and model-implied SDs. Transform the effect using those draw-specific SDs, then summarize the transformed draws. For continuous moderators, the selected raw values (for example the reference mean and mean plus/minus one reference SD) remain fixed across draws. If standardized coefficients are used, evaluate them at \(w_c/s_W^{(r)}\) in draw \(r\), not at one fixed standardized moderator value.

Point estimates evaluate the effect at the fitted parameters, or at pooled primitive parameters for MI. For MI models with products of mediator differences and the moderator, the marginal variance estimators are pooled jointly with those coefficients before taking square roots. Point estimates are not averages of nonlinear draw effects. Invalid joint draws are excluded together; use wsmed_effects(result)$diagnostics to inspect the query diagnostics.

The current effect reports from print(), summary() and wsmed_effects(), and confint() applied to extracted effects, use percentile intervals for both MC and bootstrap, with or without moderation. They use R’s type-7 quantiles. boot_ci_type affects stored legacy parameter tables; it does not change these effect intervals. See the expandable implementation notes below for the legacy conventions.

The following longer bootstrap example is not run during vignette rebuilding:

both_result <- wsMed(
  data = dat,
  M_C1 = c("M11", "M21"),
  M_C2 = c("M12", "M22"),
  Y_C1 = "Y1",
  Y_C2 = "Y2",
  W = "W",
  MP = c("b1", "d1"),
  ci_method = "both",
  standardized = TRUE
)
print(both_result)
summary(
  both_result,
  method = "mc"
)
summary(
  both_result,
  method = "bootstrap"
)
plot(
  both_result,
  method = "bootstrap"
)

When both engines are stored, print() reports both. Use method in summary() and plot() to select one engine.

Missing data and reporting

FIML and MI use the same effect definition. With fixed.x = FALSE, estimated external moments participate in the joint transformation. With fixed.x = TRUE, transformations condition on fitted external moments. Products containing an endogenous mediator are modeled with auxiliary moment equations and covariances with their upstream mediator disturbances. This preserves the predictor moment structure when a reference group changes. fixed.x applies to the remaining genuine exogenous predictors; endogenous product moments are always estimated.

MI supports MC inference and evaluates effects at pooled primitive parameters; its probing and centering reference is the first completed dataset. With MI and fixed.x = TRUE, external moments from that reference are held fixed. This does not introduce population-relative moderator probing or a new imputation procedure.

For MI models with interactions involving mediator differences, wsMed averages each marginal variance estimate over completed datasets. It pools its covariance with the primitive coefficients using delta-method within-imputation covariances and Rubin’s rules. MC samples the variances jointly with the coefficients, so the denominator is not treated as fixed. Pooling the variance itself avoids the coding dependence of evaluating a nonlinear marginal variance only after pooling covariance-model parameters. This additional variance-pooling step is specific to those endogenous products; it is not applied to every MI model. Other models obtain marginal scales from the jointly drawn model parameters. The original coefficient pooling and imputation procedure are retained.

Report the condition difference direction, model and moderated paths, moderator coding/reference and raw probe values, marginal SD definition, missing-data method, fixed.x, inference engine, number of valid draws and interval type. Distinguish standardized interaction coefficients per SD of W from conditional indirect effects at particular raw W values.

For serial and sparse models, see the custom-model tutorial. Their complete indirect effects follow the same endpoint scaling rule.

More plots for reporting

Start with plot(result) for the default display. Optional named helpers include plot_effects() for an effect forest, plot_conditional_effects() for group or reference-level point intervals, and plot_contrasts() for effect differences with their own confidence intervals. All three support standardized and the MC/bootstrap engine selection. See Plotting mediation effects and contrasts for executed examples, selection of paths and labels, and export to PDF or PNG.

Imputation compatibility

Correct standardization does not repair an imputation model that omits substantive interactions. Default raw-variable MI uses main effects. To use model-compatible external imputations, pass a list of completed wide datasets (or a mice mids object) through wsmed_fit(..., missing = "mi", mi = list(completed = completed)) or wsMed(..., Na = "MI", mi_args = list(completed = completed)). The difference scores and products are regenerated in each completion; observed cells and factor levels are checked. See the worked example for assumptions, an explicit SMC-FCS predictor matrix and convergence guidance.

Optional implementation checks

Expand numerical checks and legacy moderation-table details

These checks inspect stored internals. They are not required to request standardized results through summary(), wsmed_effects() or plot().

Check the stored point estimates

For this complete-data MC fit, the standardized overall effects must equal the raw effects divided by the fitted marginal outcome SD:

sy <- sqrt(lavaan::fitted(result$mc$fit)$cov["Ydiff", "Ydiff"])
stopifnot(isTRUE(all.equal(
  result$moderation_std$conditional_overall$Estimate,
  result$moderation$conditional_overall$Estimate / sy,
  tolerance = 1e-7
)))
stopifnot(identical(result$moderation_std$theta_curve$W_raw,
                    result$moderation$theta_curve$W_raw))

This identity concerns point estimates. It does not justify dividing raw confidence limits by the fitted SD.
